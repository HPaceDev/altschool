# Конспект звонка с заказчиком

Источник: конспект созвона в Яндекс Телемосте, передан 23 августа 2026.
Записано со слов заказчика — это не согласованные требования, а исходный
материал, из которого выросли вопросы Q-017…Q-027.

Формулировки сохранены близко к оригиналу. Там, где расшифровка выглядит
искажённой, это отмечено прямо в тексте: додумывать за заказчика нельзя.

## Продукт

Единый сервис **Alt Schools** — агрегатор информации о школах развивающего
обучения в России. Бренд заказчика — **Altschool**, основной акцент на
франшизе Altschool. Цель, названная заказчиком: развивать сообщество школ
развивающего обучения.

Платформа состоит из разделов:

1. **Агрегатор школ** — карта школ, список с возможностью сравнения,
   избранные школы, «уровни», «история квалификации», отправка заявок и
   запись в школы.
2. **Обучающая платформа** — кабинет школы: лиды, аналитика, редакционная
   модерация, контент, события школы.
3. **Франчайзинговый раздел** — работает по аналогии с агрегатором:
   экономические расчёты и информация для предпринимателей, желающих
   открыть свою школу. Большой продающий лендинг со списком всех франшиз
   Альтскула, у каждой франшизы свой личный кабинет.

## Наполнение базы школ

- Планируется парсинг данных о школах.
- Рассматривается ИИ для поиска школ по названиям сайтов и соцсетям.
- ИИ может отправлять приветственные запросы или SMS-приглашения.
- Для обзвона школ предлагается робот, ведущий диалоги голосом.

## Интеграции

- **Альфа-ЦРМ**: доступ только у Altschool Education. Франшизы Altschool
  интегрируются с CRM для отслеживания статистики.
- «Интеграция с Альфа-ЦРМ **и Японией** для отслеживания звонков» —
  «Япония» почти наверняка искажение расшифровки. Похоже на название сервиса
  коллтрекинга, но угадывать нельзя, нужно уточнить у заказчика (вопрос Q-021).

## Другие франшизы

- Altschool не хочет заниматься продвижением чужих франшиз: это отдельный
  бизнес.
- Андрей Тищенко предложил размещать на сайте информацию о франшизах
  партнёров, но это не основной акцент.
- Возможность добавления других школ рассматривается на этапе проектирования.

Здесь расхождение позиций внутри команды заказчика — зафиксировано вопросом
Q-026.

## Люди и сроки

- В проекте участвуют трое: **Андрей Тищенко, Дима, Артём**, плюс
  разработчики.
- Altschool пригласила команду Андрея Тищенко на конференцию в Менторском
  доме на Алтае **4 октября**. На конференции планируется обсуждение
  интеграции с CRM и других вопросов.

Дата конференции — единственный названный срок. Является ли она рубежом для
показа чего-либо, из конспекта не следует (вопрос Q-027).

## Что это меняет для нас

До звонка мы проектировали «довольно простой агрегатор школ». Из конспекта
следует платформа из трёх продуктов: агрегатор, кабинет школы с аналитикой и
модерацией, франчайзинговый раздел с личными кабинетами и расчётами. Плюс
парсинг, ИИ-обзвон и интеграция с CRM.

Это принципиально другой объём. Прототип менять пока не начинаем: сначала
нужно понять очерёдность разделов и что вообще входит в первый запуск —
вопросы Q-017 и Q-018.
